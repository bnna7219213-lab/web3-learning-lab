# B05 · 代币与权限（联盟网）

> 状态：未开始 ｜ 对应主线：[P05](../P05-ERC20代币基础/README.md) ｜ 网络底座：[shared/consortium-network](../../shared/consortium-network/README.md) ｜ 更新：2026-10-14
> 一句话目标：在联盟环境实现「内部积分/权益代币」，重点不是发币，而是**谁能发行、谁能销毁、跨成员如何授权**。

## 与 P05 的关系

**功能实现一致，环境语义不同。**P05 的全部知识点在本分支都要做一遍，本 README 只记录**差异与新增验收**；
共性差异见 [差异矩阵](../../shared/consortium-network/docs/04-差异矩阵-P03-P08-vs-B03-B08.md)。

| 维度 | P05（公链/anvil） | B05（联盟 QBFT） |
|------|------------------------|----------------------|
| 代币定位 | 公链可流通资产 | **联盟内部记账单位**：不可对外转让、不可兑换法币、无二级 |
| 发行权 | 合约 owner | 运营方多签 + 成员确认；变更进 M4 存证 |
| 合规 | 面向公众即触碰红线 | 限定成员范围 + 合同依据（对齐去代币化检查表） |
| 技术新增 | — | 角色矩阵测试：未授权 mint 必须 revert 且有事件留痕 |

## 验收

**分支共用四条增量**（B03–B08 一律适用）：

- [ ] 多成员：≥2 个成员账户各自发交易，nonce 互不干扰
- [ ] 零 gas：`eth_gasPrice == 0` 且 `baseFeePerGas == 0`，交易确实入账
- [ ] 终结性：交易所在块在 3 个节点查询一致，5 分钟后仍一致
- [ ] 权限负例：未授权账户/节点被拒且留下可审计记录

**本分支特有**：

- [ ] 角色矩阵 ≥6 条负例测试（未授权 mint/burn/改角色全部 revert）
- [ ] 文档写清「本代币不是虚拟货币」的三条依据
- [ ] 跨成员转账 100 笔后各成员余额与链下台账零差异

- [ ] README 可按步骤复现（含联盟网准备步骤）
