# B07 · 权益凭证（联盟网）

> 状态：未开始 ｜ 对应主线：[P07](../P07-NFT市场进阶/README.md) ｜ 网络底座：[shared/consortium-network](../../shared/consortium-network/README.md) ｜ 更新：2026-10-14
> 一句话目标：把 NFT 市场改造成**联盟内权益凭证系统**：成员间转让受控、元数据不出内网、无二级炒作入口。

## 与 P07 的关系

**功能实现一致，环境语义不同。**P07 的全部知识点在本分支都要做一遍，本 README 只记录**差异与新增验收**；
共性差异见 [差异矩阵](../../shared/consortium-network/docs/04-差异矩阵-P03-P08-vs-B03-B08.md)。

| 维度 | P07（公链/anvil） | B07（联盟 QBFT） |
|------|------------------------|----------------------|
| 定位 | 公开市场 + 版税 + 二级 | **权益发行/核销/退改**，明确关闭二级 |
| 元数据 | IPFS/Pinata | 客户内网对象存储，链上只存哈希（数据不出域） |
| 批量 | 受 gas 成本约束 | 受区块容量与单笔 gas 上限约束（需 pertxgaslimit） |
| 合规 | 数字藏品炒作风险 | 禁二级 + 实名成员 + 预收费监管口径（见 M3 卡片） |

## 知识点

- [ ] ERC-721/1155 在联盟场景的语义收缩（凭证而非藏品）
- [ ] EIP-4907 租期分离：owner/user 双角色的成员间租赁
- [ ] 元数据放内网对象存储 + 哈希上链（不依赖公网 IPFS）
- [ ] 转让限制：账户白名单 + 合约层转让策略（禁二级）
- [ ] 批量铸造与 EIP-7825 单笔 gas 上限的关系

## 技术栈

- Solidity + Foundry
- React 权益管理台
- 内网 OSS + 哈希锚定（复用 P01 Merkle 出证结构）

## 验收

**分支共用四条增量**（B03–B08 一律适用）：

- [ ] 多成员：≥2 个成员账户各自发交易，nonce 互不干扰
- [ ] 零 gas：`eth_gasPrice == 0` 且 `baseFeePerGas == 0`，交易确实入账
- [ ] 终结性：交易所在块在 3 个节点查询一致，5 分钟后仍一致
- [ ] 权限负例：未授权账户/节点被拒且留下可审计记录

**本分支特有**：

- [ ] 成员 A→B 转让成功、A→未授权成员失败且留痕
- [ ] 1000 份权益批量铸造通过（含 gas 上限验证）
- [ ] 到期自动回收 0 例外；核销 P95 < 300ms

- [ ] README 可按步骤复现（含联盟网准备步骤）
- [ ] 去代币化检查表通过（涉及对外交付时）
