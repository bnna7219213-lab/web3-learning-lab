# 01 · 联盟内权益凭证：语义收缩与实现取舍

> 对应主线：[P07 投票/市场 DApp](../P07-NFT市场进阶/docs/01-租期版税撮合与合规开关.md) ｜ 环境：Besu QBFT 4 验证者（chainId 19880601）｜ 2026-11-13
> 一句话：**P07 的「藏品」在联盟网里必须是「凭证」**——没有价格、没有二级、持有人只能是成员、到期即失效。

---

## 1. 语义收缩：四条差异怎么落到合约上

| P07 的做法 | B07 的做法 | 为什么必须这样 |
|------------|-----------|---------------|
| `NFTMarket` 合约 + `tradingEnabled` 开关 | **没有市场合约** | 联盟网的核心诉求是「禁二级」。把二级做成一个布尔开关意味着**开一次就是一次事故**；做成结构上不存在，才是默认值 |
| 版税 `ERC2981`（5% 二次销售抽成） | **取消版税** | 版税是二级市场的产物。凭证在成员间流转是「使用权安排」，不是「交易」，抽成没有依据 |
| 元数据 URI 指公网 IPFS | **链上只锚 Merkle 根，URI 指内网对象存储** | 数据不出域。链上存 URI 等于把内网拓扑泄漏到公链可查的存储里 |
| 凭证永久有效（只有 4907 的**使用权**有期限） | **凭证自身带 `validUntil`**，到期即不可转让/不可核销 | 权益类凭证（年费会员、设备配额、试验额度）天然是**有期**的；「到期自动回收 0 例外」的意思是**失效判定不依赖任何人调用** |

## 2. 合约：LabCredential

### 2.1 数据模型

```solidity
struct Batch {
    uint256 startId;      // 起始 tokenId
    uint16 count;         // 份数
    bytes32 merkleRoot;   // 元数据内容哈希树根（哈希锚定，数据不出内网）
    string baseURI;       // 内网对象存储基址，如 http://127.0.0.1:8088/ipfs/<cid>/
    uint64 validUntil;    // 有效期（0 = 长期有效）
    bool transferable;    // 是否允许成员间流转（一次性消费券可设为 false）
    address issuer;       // 发行方
}
```

**为什么用「批次」而不是「每个 token 一份元数据」**：
1000 份如果每份都存 URI + 内容哈希，就是 2000 次 SSTORE ≈ 40M gas —— 直接撞穿 EIP-7825 的单笔上限。
改成「批次存根 + tokenURI 按 id 推导」，每批只写一次链上状态，1000 份的链上成本降到 4 笔 × ~6.6M gas。

### 2.2 转让策略（禁二级的落点）

OZ v5 没有 `_beforeTokenTransfer`，策略只能写在 `_update`：

```solidity
function _update(address to, uint256 tokenId, address auth) internal override returns (address) {
    address from = _ownerOf(tokenId);
    if (from != address(0) && to != address(0)) {   // mint / burn 不受转让策略约束
        if (isExpired(tokenId)) revert CredentialExpired(tokenId);
        Batch storage b = batches[batchOf(tokenId)];
        if (!b.transferable) revert NotTransferable(tokenId);
        if (!isMember[from]) revert NotMember(from);
        if (!isMember[to]) revert NotMember(to);
        delete _users[tokenId]; delete _expires[tokenId];   // 转让清租约
    }
    return super._update(to, tokenId, auth);
}
```

语义：**只有白名单成员之间能流转**。非成员根本收不到（发行时就要求 `isMember[to]`），
也转不出（撤销成员资格即冻结）。二级炒作在结构上无处发生。

### 2.3 审计留痕：两路

| 路径 | 载体 | 特点 |
|------|------|------|
| 失败交易 | 链上 status=0 的交易 + 自定义 error（`NotMember(addr)` / `CredentialExpired(id)` / `NotTransferable(id)`） | 不可被索引、不可按主题查询，但**失败原因在 calldata/revert data 里** |
| 审计流水 | `recordBlockedTransfer()` 写 `auditEntries` + `TransferBlocked` 事件 | 可按序号查询、含操作者/时间戳；由调用方在预检失败后主动写入 |

配套的只读预检 `checkTransfer(from, to, tokenId) → (allowed, reason)` 让 DApp 在发交易前就知道会不会被拒，
并把原因码原样写进审计——**失败交易与审计记录可以交叉核对**。

### 2.4 到期自动回收 0 例外

```solidity
function isExpired(uint256 tokenId) public view returns (bool) {
    uint64 until = batches[batchOf(tokenId)].validUntil;
    return until != 0 && block.timestamp >= until;
}
```

判定只看**链上时钟**，不依赖任何人的任何调用。过期后：`transferFrom` revert、`redeem` revert、
4907 的 `userOf` 返回 0。`sweepExpired(ids)` 是**任何人**都能调的可选清理：把已失效的凭证销掉并写
`ExpiredSwept` 事件 + `sweptCount`。它的教学意义大于功能意义——**失效不需要谁来执行**。

### 2.5 哈希锚定：复用 P01 出证结构

`shared/evidence/lib/merkle-indexed.js`（P01 出证库 v2）的特征：
sha256 + 域分隔（`L`/`N`/`C`）+ **位置绑定叶子** + 奇数补 `EMPTY_LEAF` 哨兵（不复制最后一个叶子）。

合约里复刻了同一套（`sha256` 预编译 + `abi.encodePacked`）：

```solidity
function nodeHash(uint8 level, uint256 index, bytes32 left, bytes32 right) internal pure returns (bytes32) {
    return sha256(abi.encodePacked("N", level, uint32(index), left, right));
}
```

**跨语言一致性怎么保证**：不是靠两边「看起来一样」，而是
① JS 侧用 P01 原库算根与证明 → ② 根上链 → ③ 链上 `verifyProof` 重算并比对；
④ 再用「篡改叶子」与「拿 index5 的证明验 index6 的叶子」两个反例确认链上不是「怎么算都对」。

## 3. 联盟网三条硬规矩（写在 deploy.sh 头部，也写在这里）

1. **编译必须 london**：`FOUNDRY_PROFILE=consortium`。genesis 只开到 london，用 cancun 会发 PUSH0(EIP-3855)，
   部署交易**进块但 status=0**、gas 全烧光——看起来部署成功，其实没生效（B04 已踩过）。
2. **零 gas**：`--legacy --gas-price 0`。
3. **必须显式 gasLimit**：成员账户余额为 0，`eth_estimateGas` 会以「余额不足」直接失败，
   gas 估算这一步过不去 → 用固定上限（8,000,000）跳过估算。

第 3 条是最反直觉的：**零 gas 网络不豁免余额检查**。

## 4. 本轮踩到的具体坑（含解法）

| 现象 | 根因 | 解法 |
|------|------|------|
| 浏览器直连 8551 被 CORS 拒 | Besu `corsAllowedDomains=[]`（anvil 允许 localhost，所以 P07 没遇到） | 同源 RPC 代理（`serve-frontend.js` 的 `/rpc`） |
| `eth_estimateGas` 报「余额不足」 | 成员账户余额为 0 | 显式 `gasLimit` |
| 编译出的部署交易 status=0 | cancun 的 PUSH0 | `FOUNDRY_PROFILE=consortium`（london） |
| 合约报 `Undeclared identifier. Did you mean "batches" or "batchOf"?` | Solidity **不允许按名内部调用 `external` 函数** | `batchOf` 改 `public` |
| `_beforeTokenTransfer` 编译不过 | OZ v5 已移除该钩子 | 策略写进 `_update` |
| 负例「没报错」 | `await contract.method()` 在 `eth_sendTransaction` 返回时就 resolve，revert 在挖块阶段 | 等回执（`tx.wait()`）；取返回值用 `staticCall` |
| 有效期判断忽早忽晚 | 本地时钟与链上 `block.timestamp` 有偏差（节点 5s 才推进一块） | 有效期按**链上时钟**算 |
| 脚本报 `Cannot mix BigInt and other types` | ethers v6 的 `getBlockNumber()` 返回 number | 显式 `BigInt(...)` |
| `JSON.parse` 报 Unexpected token | PowerShell 5.1 的 `Set-Content -Encoding UTF8` 写 BOM | 读 JSON 统一剥 `^\uFEFF` |
| `.ps1` 里中文路径乱码 | PS 5.1 按 GBK 读无 BOM 的 .ps1 | 脚本内一律用 `$PSScriptRoot` 相对路径 |
| kubo `files/write` 一直失败 | 该版本的 MFS 行为异常 | 改用 `api/v0/add` + multipart 多文件 + `wrap-with-directory`（返回 NDJSON，最后一行是目录 CID） |

## 6. 还欠什么

- **B03 联盟水龙头与凭证发放的衔接**：领水 → 领凭证 的原子流程（B03 有水龙头服务，B07 还没有）。
- **合规口径**：预收费/退改的财务口径需要与运营方确认（M3 卡片），本轮只实现了「退改」= 撤销成员资格即冻结。
- **P08 的零 gas 语义**：单笔 gas 上限（EIP-7825）与 `contractSizeLimit` 在零 gas 网络里从「省钱」变成「省区块容量」，
  需要单独一篇（见差异矩阵对 B08 的要求）。
