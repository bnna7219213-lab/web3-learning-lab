# 01 · 组件与端口地图

> 用途：出问题时 30 秒内知道"该看哪个进程、哪个端口、哪份日志"。
> 端口默认值依据 `ethpandaops/ethereum-package` 的 `port_publisher` 说明（EL/CL P2P 发布）与各客户端公开文档；**本机未实测**（无 Docker）。

## 一条 PoS 链上的进程

| 角色 | 干什么 | 崩溃后果 | 典型实现 |
|------|--------|----------|----------|
| EL 执行层 | 执行交易、维护世界状态、提供 JSON-RPC | 不能出块也不能同步 | Geth / Nethermind / Besu / Erigon / Reth / EthereumJS / Nimbus-eth1 / ethrex |
| CL 共识层 | 信标链、fork-choice、attestation 聚合与 gossip | 失去最终性 | Prysm / Lighthouse / Teku / Nimbus / Lodestar / Caplin / Grandine |
| VC 验证者客户端 | 提案与投票（持签名私钥） | 漏签 → 罚没（轻）；双签 → 重罚没 | 与 CL 同实现，或 `use_separate_vc + vc_type` 分离 |
| Bootnode / ENR | 节点发现 | 新节点进不来 | Geth `bootnode`；CL 用 `bootstrap_nodes` |
| JWT | EL↔CL 私有通道认证 | 两者连不上（`Invalid payload id`） | 一个 32 字节文件 |
| 监控 | 指标与告警 | 故障不可见 | Prometheus / Grafana / Xatu / forkmon / tracoor |
| 压测 | 持续灌交易 | — | tx-fuzz / spamoor |

## 端口

| 端口 | 层 | 协议 | 是否需要对公网 | 说明 |
|------|----|------|----------------|------|
| 30303 | EL | tcp + udp | **是**（P2P） | 区块与交易广播；`nat_exit_ip` 决定广播出去的地址 |
| 9000 | CL | tcp + udp | **是**（P2P） | attestation 与 beacon 同步，按 subnet 订阅 |
| 8545 | EL | tcp | **否** | HTTP JSON-RPC |
| 8546 | EL | tcp | **否** | WebSocket JSON-RPC |
| 8551 | EL | tcp | **否** | 认证引擎接口（CL→EL，走 JWT） |
| 5052 | CL | tcp | **否** | CL HTTP API |
| 3500 | VC | tcp | **否** | Remote Signing / Keymanager API，泄露=私钥泄露 |
| 9090 | 监控 | tcp | **否** | Prometheus 抓取端口（Kurtosis 里 nginx 分发配置也常用 9090，注意别撞） |

> 一句话记法：**只有 30303 和 9000 是"链的端口"，其余都是"你的服务的端口"**，默认全部拒绝入站（见 `scripts/30-firewall.sh`）。

## 数据目录与容量

| 项 | 增长驱动 | 私有网经验做法 |
|----|----------|----------------|
| EL 状态 | 合约存储与账户数（不是"区块大小"） | 保留期够就行；要历史查询再上 archive |
| EL 历史/快照 | 全节点默认保留 | `el_volume_size` 显式给（默认偏小） |
| CL 数据库 | slot 数 × 每个 fork 的 checkpoint 状态 | `cl_volume_size` 显式给 |
| Blob（EIP-4844+） | blob 数量，短保留期 | 压测时最容易撑爆盘 |

## 一次交易的完整路径（把 P02/P03 的知识接上）

```text
sign(tx, chainId)            ← P01：签名域含 chainId，防跨网重放
  → EL 8545 sendRawTransaction
  → EL mempool → 30303 gossip → 其他 EL
  → 轮值 VC 把交易塞进 payload → CL 9000 广播
  → 2/3+ 权重 attestation → 2 个 epoch 后 finalized   ← P02 实验 3 的真实版本
  → 事件日志可被索引器读取                            ← P09
```
