# B09 设计：联盟链语义下的差异（与 P09 同构部分见 [P09 docs/01](../../P09-链上数据平台进阶/docs/01-设计.md)）

## 1. 终结性替代 confirmations 深度

公链索引器的核心参数是 `confirmations`（等 N 个块才敢说「这段是安全的」）。QBFT 单块终结下：

- **块高层面没有重组**：一个块被 2f+1 验证者签过即终局，不存在公链式的「浅分叉等叔块」。
- 所以 `CONFIRMATIONS=0`（B09 默认）——不需要等深度。
- 但「多节点一致性」取代了深度语义：**同一块哈希在 3 个节点上必须一致**（验收 F-3）。
  这对应公链上「等确认」的真实意图：**不是等时间，是等不会变**。
- `deep` 的另一层（跨节点 RPC 不一致 = 网络分区/节点落后）在联盟网里仍然要防：
  索引器只信一个 RPC，BFF 的 `/api/health` 暴露 `head`，运维拿它和其它节点对（验收 F-3 就是自动化版）。

## 2. 无真实分叉 ⇒ 回滚重放改「注入式」测试

P09 的分叉测试用 anvil `evm_snapshot/evm_revert` **真的**造出两条链。联盟链不能这么玩：
人为回退一个验证者的状态会破坏 4 节点共识（要么被孤立、要么全网回退），教学成本与风险都不划算。

替代方案：**注入式回滚测试**——直接篡改本地索引库的某块哈希（`UPDATE blocks SET hash='0xde…'`），
模拟「我索引过的块后来被换了」，然后跑 `syncOnce()`：

- `findCommonAncestor` 从游标往下比对本地 hash 与链上 hash → 在被篡改的高度发现不一致 → 判定 `kind=fork`
- `rollbackTo(祖先)` 删掉该高度之后的一切 → 向前重放 → 行数**完全恢复**（同一条链，没有真分叉）

这测的是**同一段代码路径**（回滚协议），且完全可重复。README 里如实标注「注入式」，不假装是真实分叉。

## 3. 批次列（batchId）是联盟权益凭证的主力筛选

`CredentialIssued(batchId, startId, count, merkleRoot, issuer)`——1000 份凭证分 4 笔发行的**批次号**就是它。
看板的「批次筛选」在 P09 上对应 listingId/orderHash，在 B09 上对应 batchId：
抽平列 `logs.batch` 直接建索引（`idx_logs_batch`），筛选实测毫秒级。

对账语义：**同一批次的凭证可以从事件重建**（startId..startId+count-1），配合 P01 出证库可离线重算 Merkle 根
——这就是「可出证」：链上只存根，索引器给出「谁、哪批、什么时候、多少份」的可查询事实。

## 4. 权限负例留痕：TransferBlocked

联盟白名单的「被拒转让」在链上留的是**审计事件**（`recordBlockedTransfer`）而不是 revert-only：
失败交易本身（status=0）不能被索引，所以合约把「被拒的尝试」也写成事件。

索引器把它照常入库 ⇒ 看板上「谁试图转给谁、被拒原因（reason）」可查——
这是 P 分支根本没有的维度（公链上没有白名单，也就没有「被拒的转让」这个概念）。

## 5. 多成员账户与数据归属

联盟链上每个成员是独立账户（非共享 hot wallet）：

- 索引器按 `fromAddr/toAddr` 抽平 ⇒ 「成员 A 的交易」与「成员 B 的交易」天然可分账查询；
- nonce 各自独立（验收 F-1 断言两账户的 tx 都入索引且互不干扰）；
- 私钥只从 `B07/env/.env.local` 读（gitignore 覆盖），**行内注释要剥**（`KEY=0xabc # 地址` 的 `# …` 部分不剥会被 ethers 当成密钥的一段，报 `invalid BytesLike value`）。

## 6. 零 gas 的两句话（B03 口径）

1. `eth_gasPrice=0`、`baseFeePerGas=0` ⇒ **免的是手续费**；
2. 转账**面值**仍要 `balance ≥ value` ⇒ **不豁免本金**（余额 0 发 1 wei 会被 `-32004 Insufficient funds for transfer` 直接拒；`value=0` 畅通）。

`01-gen-events.mjs` 的顺序就是这个语义的演示：先领水（拿本金）→ 1 wei 互转 → 零余额账户发 value=0 交易照样入块。
