# S7 · 毕业项目

> G1–G6 毕业交付：PRD、架构图、部署手册、安全与 Gas 报告、作品集描述。

## 放什么

- 每个 G 项目一个子目录（PRD、架构、部署、安全、复盘）
- 简历用 STAR 描述 3 条
- 模块拆件交付物同步登记到 `docs/00-预备/modules/` 对应卡片

## 命名约定

- 原理文：`NN-主题.md`（如 `01-哈希与共识.md`）
- 复盘文：`复盘-<项目号>-<周次>.md`
- 架构图：`架构图-<项目号>.{svg,mmd}`
- 对照精读：`lainchain对照-<合约名>.md`（每完成一个 Pxx 写一篇）

## 阶段出口（对齐 roadmap.md）

见本仓库根 [README.md](../../README.md) 项目索引表与 开发计划.md（属主仓库内容，未随本公开仓库发布） 对应里程碑。
