# shared/contracts-lib

> 跨项目复用的合约工具库（权限、累加器、Merkle 验证、错误定义）。

## 放什么

- 从 projects 抽出「第二次用到」的合约才进这里
- 必须带单测与 NatSpec

## 命名约定

- 原理文：`NN-主题.md`（如 `01-哈希与共识.md`）
- 复盘文：`复盘-<项目号>-<周次>.md`
- 架构图：`架构图-<项目号>.{svg,mmd}`
- 对照精读：`lainchain对照-<合约名>.md`（每完成一个 Pxx 写一篇）

## 阶段出口（对齐 roadmap.md）

见本仓库根 [README.md](../../README.md) 项目索引表与 开发计划.md（属主仓库内容，未随本公开仓库发布） 对应里程碑。
