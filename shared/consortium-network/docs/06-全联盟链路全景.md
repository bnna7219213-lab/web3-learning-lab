## 三、B09 联动的技术边界

1. **事件源不是写死地址**：`indexer/config.js:watchSources()` 从 B05/B06/B07/B08 部署记录发现合约；缺失时跳过软依赖源。
2. **新增源必须补历史**：源清单或链身份变化会记录指纹、清理退出源的日志、回退游标并完整重扫。I 组实测“移除 B05 → 清理 → 重接入 → 历史 Transfer 补回”。
3. **同名不等于同布局**：ERC20 与 ERC721 的 `Transfer` topic0 相同，但前者金额在 `data`、后者 tokenId 在 `topics[3]`。B09 按日志结构解码，禁止把 ERC20 金额当 NFT 编号。
4. **派生状态分口径**：`assets/holders` 仅统计 ERC721；`fungibleBalances` 用 BigInt 精确重放 ERC20 最小单位余额，并与链上 `balanceOf` 对账。
5. **查询不等于证明**：页面展示来自本地索引；链上条数复核、余额对账、跨项目部署记录与三节点终结性共同构成证据。
6. **快照可用性**：RPC 离线时 B09 明示“本地索引快照”，不伪装成实时链状态；B04/B06 的交易操作仍要求节点在线。
