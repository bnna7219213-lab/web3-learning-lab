# shared/scripts

> 通用脚本：一键本地链、部署录制、Gas 报告、verify 质量门禁。

## 放什么

- 脚本入口统一在 run 文件里，禁止临时调试脚本混入（lainchain 教训）

## 命名约定

- 原理文：`NN-主题.md`（如 `01-哈希与共识.md`）
- 复盘文：`复盘-<项目号>-<周次>.md`
- 架构图：`架构图-<项目号>.{svg,mmd}`
- 对照精读：`lainchain对照-<合约名>.md`（每完成一个 Pxx 写一篇）

## 阶段出口（对齐 roadmap.md）

见本仓库根 [README.md](../../README.md) 项目索引表与 开发计划.md（属主仓库内容，未随本公开仓库发布） 对应里程碑。
