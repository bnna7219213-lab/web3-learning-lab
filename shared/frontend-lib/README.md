# shared/frontend-lib

> 前端复用组件与逻辑（钱包连接、ABI 装载、表格/图表、格式化）。

## 放什么

- 先零依赖/Vue-React 无关的工具函数，再考虑组件库
- ABI 由部署脚本自动产出，不手写

## 命名约定

- 原理文：`NN-主题.md`（如 `01-哈希与共识.md`）
- 复盘文：`复盘-<项目号>-<周次>.md`
- 架构图：`架构图-<项目号>.{svg,mmd}`
- 对照精读：`lainchain对照-<合约名>.md`（每完成一个 Pxx 写一篇）

见本仓库根 [README.md](../../README.md) 项目索引表与 开发计划.md（属主仓库内容，未随本公开仓库发布） 对应里程碑。
